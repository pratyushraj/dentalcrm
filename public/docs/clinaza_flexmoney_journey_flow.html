End-to-End In-Clinic Patient Journey & Architecture

Doctor pre-checks patient credit limit chairside ➔ Full procedure financed OR Split Payment (Counter Down Payment + Balance EMI) ➔ Patient completes private OTP & e-NACH on smartphone ➔ Instant S2S webhook disbursal.

STEP 01
Pre-Check Limit
Patient scans static desk QR standee OR desk queries mobile in Clinaza to check pre-approved credit limits.
Standee QR / In-Store API
STEP 02
Estimate & Split
If limit covers 100% ➔ Full EMI. If ₹1L cost and ₹70K limit ➔ ₹30K desk down-payment + ₹70K balance EMI.
Split / Full EMI
STEP 03
WhatsApp / SMS Link
Desk pushes instant WhatsApp/SMS payment link to patient's phone. Web SDK opens modal for the net balance.
Instant Mobile Link
STEP 04
OTP & e-Mandate
Patient selects tenure (3–24 mo), enters bank OTP, and signs digital e-NACH mandate on their own phone.
Bank OTP / e-NACH
STEP 05
Disbursal & Start
Flexmoney dispatches real-time webhook. Doctor sees 100% secured funds; treatment starts immediately!
Real-Time Webhook
💡
Clinaza Split-Payment Affordability Engine (e.g. ₹1,00,000 Treatment):
Case A (100% Limit Available): Treatment ₹70,000 | Pre-approved limit ₹80,000 ➔ 100% converted to monthly EMIs with zero cash down.
Case B (Partial Limit / Co-Pay): Treatment ₹1,00,000 | Pre-approved limit ₹70,000 ➔ Patient pays ₹30,000 Down Payment at clinic counter (UPI/Card/Cash) + ₹70,000 balance on monthly EMIs via Flexmoney InstaCred. Eliminates treatment deferrals and eliminates clinic bad debt!
Flexmoney Developer Integration Suites (flexmoney.in/developers): Architecture Selection
1. Web SDK
JAVASCRIPT / TYPESCRIPT PRIMARY PATIENT FLOW

Drop-in responsive checkout modal embedded directly into Clinaza mobile web checkout. When patient clicks the instant WhatsApp / SMS payment link on their smartphone, the SDK handles mobile OTP authentication, multi-lender credit line selection (3–24 months), and digital mandate completion privately on the patient's device.

  • ✓ Single <script> tag setup with responsive, visually native UI
  • ✓ Private OTP verification & tenure selection (no receptionist screen peeking)
  • ✓ Paperless e-NACH auto-debit setup in under 2 minutes
2. API Suite — Online
REST API PRIMARY BACKEND ENGINE

Server-to-server REST integration for complete transaction lifecycle management. Clinaza backend creates order tokens, passes clinic identifiers, tracks transaction states, and consumes real-time webhook callbacks upon loan approval and disbursement to unlock immediate chairside treatment.

  • ✓ Eligibility check & S2S order token generation
  • ✓ Multi-lender dynamic routing & offer surfacing across banking rails
  • ✓ Real-time webhook callbacks for instant sanction & disbursal status
3. API Suite — In-store
REST API DESK PRE-CHECK

Purpose-built API for assisted counter pre-qualification. Receptionists enter patient mobile number to perform an instant soft credit limit check across lenders before the doctor presents the final high-ticket procedure estimate (implants, aligners, rehabilitation).

  • ✓ Instant pre-approved credit visibility prior to consultation
  • ✓ Reduces drop-offs for high-ticket (₹50K–₹2L) planned treatments
  • ✓ Zero documentation required for pre-qualification
4. CRM Integration
REST API / WEBHOOKS PRACTICE OS SYNC

Direct synchronization of Flexmoney transaction events into Clinaza's clinic operating system. Automatically updates patient treatment records, flags approved EMI disbursements, reconciles practice accounts, and schedules procedure appointments.

  • ✓ Real-time loan status push directly into clinic CRM calendar
  • ✓ Automated clinical chart update upon disbursal confirmation
  • ✓ End-of-day financial reconciliation for practice accountants
